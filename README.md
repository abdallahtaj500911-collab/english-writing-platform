# 📚 منصة تعلم كتابة اللغة الإنجليزية
## English Writing Learning Platform

منصة تعليمية تفاعلية لتحسين مهارات كتابة اللغة الإنجليزية مع مساعد ذكاء اصطناعي

### ✨ المميزات الرئيسية

- 🎯 **مستويات متعددة** - من المبتدئ إلى المتقدم
- 📝 **تمارين تفاعلية** - ترجمة مفردات وجمل عربية إلى إنجليزية
- 🤖 **مساعد ذكي** - روبوت يصحح الأخطاء ويقدم اقتراحات
- ✅ **تصحيح فوري** - تحديد الأخطاء الإملائية والنحوية
- 📊 **تتبع التقدم** - حفظ إحصائيات الأداء
- 📚 **قواعس اللغة** - شرح قواعد الكتابة
- ⚙️ **إعدادات مخصصة** - تخصيص تجربة التعلم

### 🛠️ التقنيات المستخدمة

- **HTML5 + CSS3** - واجهة تفاعلية
- **JavaScript (Vanilla)** - منطق التطبيق
- **LocalStorage** - حفظ تقدم المستخدم

### 📦 هيكل المشروع

```
english-writing-platform/
├── index.html              # الصفحة الرئيسية
├── css/
│   ├── style.css           # أنماط رئيسية
│   └── responsive.css      # أنماط التجاوب
├── js/
│   ├── app.js              # البرنامج الرئيسي
│   ├── ai-bot.js           # منطق الروبوت الذكي
│   ├── storage.js          # إدارة التخزين
│   └── grammar-rules.js    # قواعس اللغة
├── data/
│   ├── vocabulary.json     # المفردات والجمل
│   └── levels.json         # تعريف المستويات
└── README.md
```

### 🚀 البدء السريع

1. استنسخ المستودع
2. افتح `index.html` في المتص��ح
3. اختر مستوى وابدأ التعلم

### 📖 الاستخدام

1. **اختر المستوى** - ابدأ من المبتدئ
2. **اقرأ الجملة العربية** - المطلوب ترجمتها
3. **اكتب الترجمة** - بالإنجليزية
4. **اضغط "تحقق"** - الروبوت سيصحح الأخطاء
5. **انتقل للمستوى التالي** - عند النجاح
